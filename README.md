# Student Performance Tracker
A Python-based project that helps manage student details and results efficiently using Object-Oriented Programming (OOP) concepts.

---

## 📘 Project Overview

The **Student Result Management System** is designed to:
- Store student details (ID, name, class)
- Record marks for multiple subjects
- Calculate total and average marks
- Assign grades (A, B, C, Fail)
- Generate performance and summary reports

This project focuses on practical implementation of OOP, modular programming, and exception handling.

---

## ⚙️ Features

- Add and manage student information  
- Record and update subject marks  
- Automatically calculate total and average  
- Grade assignment based on average score  
- Display detailed and summary reports  
- Menu-driven console interface  

---

## 🧠 Concepts Used

- Classes and Objects  
- Functions and Modular Programming  
- Dictionaries and Lists  
- Exception Handling  
- Console-based User Interface
